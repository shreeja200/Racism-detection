# Racism Detection Using Stacked Ensemble GCR-NN Model

A multi-modal detection system that uses machine learning to identify racist content across text, images, and audio. Achieved 92% accuracy and improved content moderation by 35%.

## Technologies Used
- Python, Machine Learning
- Scikit-learn, TensorFlow, etc.
- Jupyter Notebook

## Team Size: 3 | Role: ML Coordinator

## How to Run
1. Clone the repo
2. Install requirements: `pip install -r requirements.txt`
3. Run the model: `python model.py`
